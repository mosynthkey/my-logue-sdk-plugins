User units, from this page to the hardware.

PulseFold is an oscillator. Echo is a delay for NTS-1 mkII and NTS-3. Chrome or Edge can send mkII units over USB MIDI. Other browsers can download the file for KORG KONTROL Editor. NTS-3 units are download-only for now.

USB MIDI

Send to NTS-1 mkII

Connect the kit over USB-C, then enable MIDI.

This browser has no Web MIDI API. Use Chrome or Edge on desktop, or download the unit file and send it with KORG KONTROL Editor.

NTS-1 mkII often exposes two USB MIDI ports. Pick the last NTS-1 port if identity fails. Oscillator slot 0 usually holds factory WAVES. Echo uses delay slots.
