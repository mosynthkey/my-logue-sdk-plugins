# WavSlice

NTS-3 `genericfx` that plays **one bar of WAV**, tempo-locked to the host, and
chops it on the pad. Any 1-bar drum loop, vocal chop, or stab will do. This is
not an amen plugin; AmenTime is the synthesized amen-style slicer.

Hold the pad to run on a tempo step grid. Tap position does not pick the start
16th (UKGarage-style). X = reverse chance. Y = slice grid. STRT (Edit) offsets
the walk origin.

| Param | Role | What it does |
| --- | --- | --- |
| STRT | Edit | Which 16th of the bar the walk starts from (not pad X) |
| SIZE | Y | Slice length: 1/4, 1/8, 1/16, 1/32 of a bar |
| MIX | Depth | Dry/wet |
| TUNE | Edit | Extra pitch around tempo-locked playback (±1 octave) |
| RPT | Edit | RUN walks through slices. LOCK retriggers the start slice |
| REVS | X | Chance each slice plays backwards |
| HOLD | Edit | GATE = hold to play. LATC keeps running after release |

Experimental: open the site with `?experimental`.

## Default loop

The unit ships `assets/default-loop.wav`: an original 120 BPM backbeat
(kick on 1 and 3, snare on 2 and 4, eighth-note hats). It is CC0 / public
domain, generated by `scripts/make_default_loop.py`. It is **not** Amen,
Funky Drummer, or any other copyrighted break.

Rebuild that WAV:

```bash
make -C plugins/wavslice default-loop
```

## Embed your own WAV

The slicer always plays **one bar**. Put a 1-bar WAV at `assets/loop.wav`
(gitignored) and rebuild, or use `make embed`:

```bash
# 1-bar WAV: BPM is inferred from duration (2.0s → 120 BPM, ~1.765s → 136 BPM)
make -C plugins/wavslice embed WAV=/path/to/your-loop.wav

# Longer file: pass the loop BPM and where the bar starts
make -C plugins/wavslice embed WAV=/path/to/break.wav BPM=136 START=2.4

# Then flash
make -C plugins/wavslice install GCC_BIN_PATH=/path/to/gcc-arm-none-eabi/bin
```

`make embed WAV=...` also writes a trimmed 1-bar copy to `assets/loop.wav`,
so later `make install` / CI-style target builds keep using your loop.
`loop.wav` wins over `default-loop.wav`. Do not commit it unless you have
the right to redistribute that recording.

Same thing with the script directly:

```bash
python3 plugins/wavslice/scripts/embed_wav.py \
  --wav /path/to/your-loop.wav \
  --write-loop plugins/wavslice/assets/loop.wav \
  --out plugins/wavslice/dsp/wavslice_pcm.h
```

`--bpm` is optional. If omitted, BPM is `240 * bars / duration` of the file
after `--start` (`--bars` defaults to 1). 16-bit WAV works with Python only;
other formats need `ffmpeg` on PATH.

The hardware unit stores a 12 kHz 8-bit copy so it fits the NTS-3 size
budget. Playback rate follows host tempo, so the bar stays one bar long.

## Build

From this plugin directory:

```bash
make install GCC_BIN_PATH=/path/to/gcc-arm-none-eabi/bin
make test
make wasm EMCC_BIN_PATH=/path/to/emsdk/upstream/emscripten
```

From the usual target directory (`make unit` at the repo root does this):

```bash
make -C plugins/wavslice/targets/nts-3_kaoss install \
  GCC_BIN_PATH=/path/to/gcc-arm-none-eabi/bin
```

`PRE_ALL` regenerates `dsp/wavslice_pcm.h` from `assets/loop.wav` when that
file exists, otherwise from `assets/default-loop.wav`.
