# WavSlice sample source

WavSlice is a **generic 1-bar WAV slicer**. The stock file is an original
drum loop, not a copyrighted break.

| File | License | What it is |
| --- | --- | --- |
| `assets/default-loop.wav` | CC0 (public domain) | Original 120 BPM backbeat generated by `scripts/make_default_loop.py`. Kick 1+3, snare 2+4, eighth hats. Not Amen, not Funky Drummer, not the Winstons. |
| `assets/loop.wav` | yours | Optional local override (gitignored). Wins over the default at build time. |

Attribution / a copyright notice does **not** grant a license to redistribute
The Winstons' *Amen, Brother* or other third-party recordings. Do not commit
those files or PCM derived from them.

## Rebuild the default loop

```bash
python3 plugins/wavslice/scripts/make_default_loop.py \
  --out plugins/wavslice/assets/default-loop.wav
```

## Embed a local WAV

See `README.md`. Short version:

```bash
make -C plugins/wavslice embed WAV=/path/to/your-loop.wav
```
